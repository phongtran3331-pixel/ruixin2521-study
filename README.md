# 睿信2521学习交流站

## 目录结构

```
ruixin2521-study/
├── index.html              # 主页面
├── css/style.css           # 样式文件
├── js/app.js               # 前端逻辑
├── data/                   # 数据索引文件夹（自动生成）
│   ├── competitions.txt        # 竞赛信息数据
│   ├── class_files_index.json  # 班级文件索引
│   └── notices_index.json      # 通知索引
├── class_files/            # 班级文件文件夹（树状结构）
│   ├── 高等数学/
│   │   ├── 复习资料/
│   │   └── 试卷/
│   ├── 大学物理/
│   └── 英语/
├── notices/                # 通知文件夹（每条通知一个文件夹）
│   ├── 2026-09-06_网站正式上线试运行/
│   │   └── 通知.txt
│   └── ...
├── scripts/                # Python 工具脚本
│   ├── scan_all.py         # 统一扫描工具
│   ├── launch.py           # 启动器
│   └── get_ip.py           # 获取网络信息
├── start.bat               # 一键启动
├── update.bat              # 更新索引
└── README.md               # 本文件
```

## 使用说明

### 1. 启动网站

双击 `start.bat`，会自动：
- 扫描 `class_files/` 和 `notices/` 生成索引
- 启动 Python 本地服务器（端口 8080）
- 显示局域网访问地址

### 2. 添加班级文件

在 `class_files/` 下创建文件夹结构，例如：
```
class_files/
├── 高等数学/
│   ├── 复习资料/
│   │   └── 第一章复习.pdf
│   └── 试卷/
│       └── 2025期中试卷.pdf
```

网页上会显示文件夹树，可点击进入浏览。

### 3. 添加通知

在 `notices/` 下创建文件夹，例如：
```
notices/
└── 2026-09-06_网站正式上线试运行/
    ├── 通知.txt
    └── 附件.pdf
```

`通知.txt` 格式：
```
标题: 通知标题
时间: 2026-09-06
紧急: 是/否
内容: 通知具体内容...
```

同一文件夹下的其他文件会自动作为附件展示。

### 4. 添加竞赛信息

编辑 `data/competitions.txt`，按以下格式添加：

```
竞赛名称: XXX大赛
报名截止时间: 2026-09-30
比赛时间: 2026-10-15
竞赛种类: 编程/数学/电子/...
评价: 难易程度=低/中/高, 重要性=低/中/高, 等级=院级/校级/省部级/国家级/国际级, 性价比=低/中/高
官网链接: https://example.com
---
```

### 5. 更新索引

当 `class_files/` 或 `notices/` 有变动时，双击 `update.bat` 刷新索引。

## 技术说明

- **纯前端实现**：无需后端服务器，数据以文本/JSON文件存储
- **树状文件浏览**：`class_files/` 支持任意层级文件夹
- **通知附件系统**：每条通知独立文件夹，`通知.txt` + 附件
- **局域网共享**：利用 Python 内置 http.server 模块
